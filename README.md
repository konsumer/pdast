# pdast

Convert PureData `.pd` patches to a JSON AST, and from there to other formats.

The project is a Rust workspace with five crates:

| Crate                                  | What it does                                                             |
| -------------------------------------- | ------------------------------------------------------------------------ |
| [`pdast`](pdast/README.md)             | Core library — parse `.pd` → AST, emit AST → `.pd`, JSON serialization   |
| [`pd2ast`](pd2ast/README.md)           | CLI — load a patch from disk (resolving abstractions) and print JSON     |
| [`ast2pd`](ast2pd/README.md)           | CLI — convert a JSON AST back to a `.pd` patch file                      |
| [`pdast2faust`](pdast2faust/README.md) | CLI — read a JSON AST and generate Faust DSP code                        |
| [`pdast2wclap`](pdast2wclap/README.md) | CLI — read a JSON AST and generate a self-contained CLAP-wasm plugin (C) |

## Installation

You can find pre-built versions of the CLI tools on [releases](https://github.com/konsumer/pdast/releases). Just download the correct archive for your platform/cpu, and put them in your path.

### javascript

If you want to use it as a library in a web-page, or node/bun/deno/etc app it's available at [@konsumer/pdast](https://www.npmjs.com/package/@konsumer/pdast).

```js
// the main lib
import { parse, emitPatch } from '@konsumer/pdast'

const result = parse(pdFileContent)

// web-components you can use in your own thing
import '@konsumer/pdast/components'

// now you have these (see web/index.html for usage)
// <pd-file-drop />
// <pd-loader/>
// <pd-ast-viewer/>
// <pd-patch-graph/>
```

### rust

If you have rust tooling installed, you can also do this:

```sh
cargo install --path pd2ast
cargo install --path ast2pd
cargo install --path pdast2faust
cargo install --path pdast2wclap
```

Or build everything without installing:

```sh
cargo build --release
# binaries at target/release/pd2ast, target/release/ast2pd, target/release/pdast2faust, target/release/pdast2wclap
```

### python

Make sure you have [the CLI tools](https://github.com/konsumer/pdast/releases) in your path, and then use [pdast.py](https://raw.githubusercontent.com/konsumer/pdast/refs/heads/main/pdast.py) in your own thing:

```py
from pdast import ast2pd, pd2ast, pdast2faust

print(a['root']['nodes'])

print(ast2pd(a))
#N canvas 0 50 450 300 12;
#X obj 30 50 osc~ 440;
#N canvas 0 50 200 150  0;
#X obj 20 30 inlet~;
#X obj 20 60 *~ $1;
#X obj 20 90 outlet~;
#X connect 0 0 1 0;
#X connect 1 0 2 0;
#X restore 30 80 pd mygain 0.5;
#X obj 30 120 dac~;
#X connect 0 0 1 0;
#X connect 1 0 2 0;
#X connect 1 0 2 1;

print(pdast2faust(a))
"""
// Generated by pdast2faust
import("stdfaust.lib");

// osc~
pd_oscs = os.osc;
// inlet~
pd_inlets = _;
// *~
pd__s = *;
// outlet~
pd_outlets = _;
// dac~
pd_dacs = _,_;

process = n2
with {
  n0 = pd_oscs(440);
  n1 = n2;
  n2 = (n1, n1) : pd_dacs;
};
"""
```

## Running tests

```sh
cargo test --workspace
```

The test suite covers: parsing all node types, object ID assignment, connections, inline sub-patches, abstraction loading, GUI objects, arrays, PD roundtrip (parse → emit → re-parse), and JSON roundtrip.
